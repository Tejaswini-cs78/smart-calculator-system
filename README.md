SMART CALCULATOR SYSTEM

Calculate. Understand. Learn.

A responsive and interactive Smart Calculator System designed to perform mathematical calculations with clear results and easy-to-understand explanations.

Project Overview

The Smart Calculator System is a web-based application that brings multiple mathematical and financial calculation tools together in one platform. It provides an intuitive interface, responsive design, and calculation features for students and everyday users.

Features

- Basic Calculator – Perform addition, subtraction, multiplication, division and other basic operations.
- Scientific Calculator – Perform trigonometric, logarithmic, exponential and advanced mathematical calculations.
- Algebra – Solve equations and calculate unknown variable values.
- Geometry & Mensuration – Calculate areas, perimeters, volumes and surface areas of different shapes.
- Statistics – Calculate mean, median, mode, range, variance and standard deviation.
- Unit Converter – Convert values between supported measurement units.
- Finance Calculator – Calculate percentages, profit and loss, simple interest, compound interest and loan EMI.
- Graphing – Visualize supported mathematical functions.
- Calculation History – Review previous calculations.
- Progressive Web App (PWA) – Supports app-like installation on compatible devices.

Getting Started

Follow these steps to run the project locally.

Prerequisites

- Node.js
- npm
- Git

Installation

1. Clone the repository:
   
   "git clone https://github.com/Tejaswini-cs78/smart-calculator-system.git"

2. Open the project folder:
   
   "cd smart-calculator-system"

3. Install dependencies:
   
   "npm install"

4. Start the development server:
   
   "npm run dev"

5. Open the local URL displayed in your terminal.

Production Build

To create a production build, run:

"npm run build"

The production files will be generated in the "dist" folder.
